# Eighty hours — A Kinder Walk

A walking picture game in the house we already have.
No new app. No new face. Same plates, wall, film, goal, PWA.

Hours are honest. They assume one builder who already knows this repo.

## 0. Lock (2h)
- Keep bpeace as the riff checkpoint.
- Production Vercel stays the old door until a chosen tree is accepted.
- Preview is the only place new rooms go first.
- Service worker cache bump only when new media lands (`sae-media-9`).
- Hidden keep docs copied to `public/__keep/`.

## 1. The wall that wanders (8h)
Already drafted, not live.
- Closed wall: 2D pan, wheel and swipe both ways.
- Open look: scroll/pinch = zoom. Swipe L/R at zoom 1 = next/back.
- Hand mode: grab pans the picture. Next/back only on marks.
- Gold dot = this plate has a clip.
- Glue wheel skips `.wall`.
- Film potato stays pan-x only.

## 2. Play is a tap (6h)

## 5. Four worlds as rooms, not maps (16h)
Peachfall Home, Forest listen, Porch lantern, Red rain weather,
then Noctalia, Grotto, Beyond — see WORLDS.md.
Each world:
- one ground still
- mid / fin for rise / delve
- optional 6s play
- two or three semiotic marks
- one friend who can be met here
Do not build a combat loop. Soft can be powerful means a look, a lantern, a shared peach.
